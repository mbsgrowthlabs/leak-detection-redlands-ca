Tools and methods

Tools and Methods We Use

01

Acoustic Leak Detection

We listen for the sound of escaping water underground. This pinpoints the leak without digging.

02

Thermal Imaging Camera (Fluke)

We see temperature differences from wet soil. This shows the leak path under the deck.

03

Pressure Testing Kit

We isolate each plumbing line and pressurize it. A drop in pressure confirms a leak.

04

Pipe Locator (RIDGID)

We trace the underground plumbing to mark the exact repair spot.

05

Video Pipe Inspection Camera

We look inside suspect lines for cracks, root intrusion, or corrosion.

06

Moisture Meter

We measure water content in the soil and deck to map the wet zone.

07

Bucket Test

We mark the pool level and set a bucket of water on the step. If the pool drops faster than the bucket, you have a leak. This simple test confirms the problem before we use tools.

08

Pressure Isolation

We plug each return and suction line and pressurize it. If a line loses pressure, the leak is in that run. This narrows the search to a single line.

09

Dye Testing

We apply leak detection dye around the skimmer, light niche, and fittings. If the dye is pulled into a crack, we have found the leak. This works well on shell leaks.

10

Thermal Mapping

We scan the deck and soil with a thermal imaging camera. Wet areas show a different temperature. This maps the leak path without cutting.
